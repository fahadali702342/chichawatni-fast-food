# 🍔 Chichawatni Crave Station

A modern, responsive web application for Chichawatni's premier fast food restaurant. Order delicious burgers, shawarma, pizza, and fried chicken with convenient delivery to your doorstep in Chichawatni.

## 🌟 Features

- **Interactive Menu**: Browse categorized menu items (Burgers, Shawarma, Pizza, Deals)
- **Shopping Cart**: Real-time cart management with price calculations in PKR (₨)
- **Online Ordering**: Easy checkout with WhatsApp integration
- **Delivery Tracking**: Delivery to Chichawatni area (Kamboh Chowk, Main Bazar, and surrounding areas)
- **Responsive Design**: Mobile-first, works on all devices
- **Local Payment**: All prices in Pakistani Rupees (PKR)

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/fahadali702342/chichawatni-fast-food.git
   cd chichawatni-fast-food
   ```

2. Open `index.html` in your browser or use a local server:
   ```bash
   python -m http.server 8000
   # or
   npx http-server
   ```

3. Visit `http://localhost:8000` and start ordering!

## 📱 Order Process

1. Browse the menu and add items to your cart
2. Adjust quantities as needed
3. Proceed to checkout
4. Enter your delivery address in Chichawatni
5. Confirm order via WhatsApp
6. Enjoy your meal! 🎉
